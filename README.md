# Псков. Историко-культурное наследие

Материалы блока командного проекта ИТМО по микроурбанистике. Готовый [самостоятельный отчёт в PDF](output/pdf/Наследие_Пскова.pdf) содержит выводы, четыре карты и условия применения предложений. Исследование показывает, как крепость, храмы, гражданская застройка и послевоенная реставрация читаются в городской среде. Для Покровского угла выделены две точки обследования перед уточнением фломастер-плана.

## Воспроизведение

Откройте [ноутбук](notebooks/heritage.ipynb) с ядром проектного `.venv` и выполните все ячейки. Из корня проекта в командной строке:

```bash
PATH="$PWD/.venv/bin:$PATH" .venv/bin/jupyter nbconvert --to notebook --execute \
  notebooks/heritage.ipynb --output-dir=/tmp --output=pskov-heritage-executed.ipynb \
  --ExecutePreprocessor.timeout=120
.venv/bin/python -m pytest -q
```

Для переноса на другую машину задайте `PSKOKN_DIR` и `PSKOV_BLOCKSNET_DIR`. Первый каталог содержит локальный CSV ЕГРОКН, границу округа OSM 1050399, областную границу, исходный GeoPackage и PBF. Второй нужен для сравнения трёх GeoJSON. Имена файлов и хеши см. в каталоге источников и `data/processed/source_inventory.csv`. Выходы записываются в `data/processed/` и `maps/`. Командные PDF хранятся локально с манифестом и не требуются для генерации карт. Для передачи копий нужно сверить условия доступа с командой.

Обменные данные записаны в EPSG:4326. Карты города, области и обследования строятся в EPSG:32635. Схема охранных границ сохраняет исходную МСК-60. 301 номер локальной выгрузки попал в пространственный отбор по имеющимся координатам. Числа геометрических записей унаследованного GeoPackage приведены отдельно. Сценарные точки связаны пешеходным путём по OSM длиной около 245 м. Охранная карта содержит обзорное наложение. Для определения режима места установки нужна кадастровая проверка, а для оценки проходимости — натурный осмотр.

В GitHub входят исходный код, отчёт, карты, небольшие производные слои и манифесты. Просмотр приложенных актов и командных PDF требует локальных копий из манифестов. Полный GeoPackage и таблица записей ЕГРОКН создаются ноутбуком из внешних исходников. Шрифты карт и PDF — Liberation Sans и Liberation Serif, предусмотрен резервный DejaVu.
