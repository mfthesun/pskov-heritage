- Локальный `PSKOKN/данные и материалы/pskov_oblast.pbf`, SHA-256 `75ee1b676755f8e1b5bd0b558af7b51d5d948fd188932328930356a623330db6`. Заголовок PBF содержит `timestamp=2026-06-17T23:00:00Z`, `osmconvert 0.8.11` и API OSM. CRS выгрузки EPSG:4326. Для карт извлекались пять именованных населённых пунктов по OSM ID, полигональная вода Великой и Псковы, разрешённые классы улиц, фрагменты укреплений и два конкретных подхода. Карточка указывает обновление 26.03.2026 и охват 2001–2025. Ранее при просмотре локального parquet зафиксированы строки начиная с 2000 года. [Выпуск и лицензия](https://kontikimaps.ru/how-old/cities250/datasets/), [происхождение дат](https://kontikimaps.ru/how-old/cities250/process/).
